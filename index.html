Apple Santé · BPM réels

Nouveau · v6

WHOOP peut écrire les mesures cardiaques de tes entraînements dans Apple Santé. RunLab ne peut pas lire Apple Santé directement depuis Safari : importe un export.xml Apple Santé ou un CSV de mesures cardiaques horodatées. Traitement local, sans serveur.

Aucune mesure Apple Santé importée.

Pour un XML : dans Santé → profil → Exporter toutes les données de santé, décompresse le ZIP puis sélectionne apple_health_export/export.xml. Pour un CSV : colonnes date/heure et bpm (avec, si possible, la source WHOOP). Un export Apple Santé complet peut être volumineux ; l’import peut être long sur iPhone. Les mesures sans source WHOOP identifiable ne seront pas présentées comme provenant de WHOOP.
